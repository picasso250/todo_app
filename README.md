# 心流驾驶舱 - Flow Dashboard

一个极简风格的专注时间管理应用，采用赛博朋克美学设计。

## 技术栈
- HTML5 + TailwindCSS + Alpine.js
- 单文件架构，轻量高效
- 响应式设计

## 功能特性
- 🎯 看板式任务管理 (Todo/Doing/Done)
- ⏰ 专注倒计时器
- 🎨 赛博朋克深色主题
- ⚡ 零配置启动

## 快速开始
直接在浏览器中打开 `index.html` 即可使用。

## 目录结构
```
todo_app/
├── index.html          # 主应用文件
├── README.md           # 项目说明
└── assets/             # 静态资源 (如需要)
```

## 使用说明
1. 在左侧看板添加任务
2. 点击任务的播放按钮开始专注
3. 倒计时自动启动，进入心流状态
4. 完成后任务自动移至 Done 列表
